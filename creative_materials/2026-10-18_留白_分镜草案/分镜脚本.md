# 《留白》分镜脚本（草案 v1，待确认）

> 为什么天天联系的人，话越来越少；偶尔联系的人，反而有说不完的话？

- **规格**：横屏 1920 × 1080，30 fps，约 3 分 15 秒
- **声音**：不配音，用“字幕旁白”（大字慢慢浮现，像自言自语）+ 合成的钢琴氛围铺底 + 消息提示音、打字声
- **人物**：
  - **我**（小林）：叙述者，右侧蓝色气泡
  - **阿然**：天天聊的朋友，五年，聊天记录几万条
  - **老周**：大学室友，三个月才聊一次

## 视觉系统：四种画面交替出现

| 画面 | 用途 | 样子 |
| --- | --- | --- |
| ① 聊天记录 | 生活感，讲“发生了什么” | 深色背景上悬浮一部手机或一块聊天面板，真实的微信式气泡、时间戳、“对方正在输入…” |
| ② 科普卡（PPT 式） | 讲“为什么” | 大号章节编号“01 / 02 / 03…”，一句标题，一到两行要点，干净的排版和留白 |
| ③ B-roll 解释动画 | 把道理变成图 | 水滴与杯子、火花计数器、冰山、两个生活圆圈、柱状图，都是简洁的几何动画 |
| ④ 词海星空 | 情绪段落，全片的记忆点 | 深蓝夜空，聊天记录里的词像星星一样漂浮，常说的词又大又亮，真正想说的话又小又暗，藏在角落 |

统一色调：深海军蓝夜空做底色，暖白文字；阿然一侧偏暖橙，老周一侧偏青蓝，“我”是蓝色。字幕旁白用衬线体，界面文字用黑体。

## 6 · 为什么好久不见，反而聊得好（2:14–2:42）

| 镜头 | 画面 | 字幕旁白／文字 | 声音 |

| 6-1 | 科普卡：**04　距离，制造了话题** | | |
| 6-2 | B-roll：两个圆圈代表两个人的生活。天天联系时几乎完全重叠；不联系的三个月里慢慢漂开，没重叠的部分亮起来，标着“你不知道的事” | 分开的日子，让我们的生活有了不重叠的部分。 | |
