# 《AI 甄嬛传》第一集 · 朕只是想改个标题

本作品是 `sitcom-flat` 风格的示例。用户是皇上，六个 AI 是后宫妃嫔。皇上的奏折标题错了一个字（“奏折”写成“奏拆”），众妃轮流出手，越改越乱，最后熹贵人一笔改好。

![关键帧](preview/keyframes.jpg)

| 角色 | 位份 | 介绍卡标签 | 本集的梗 |
| --- | --- | --- | --- |
| ChatGPT | 对妃 | 你说得**对** | 每句都是“你说得对”，然后把奏折连同预算全部重写 |
| Gemini | 文妃 | 文笔**满分** | 写出华丽骈文，却说“‘拆’字太美了，特意保留了” |
| Grok | 粗嫔 | 口无**遮拦** | 张口就骂，连皇上也骂，全程“哔——” |
| DeepSeek | 深贵人 | 换个**话题** | 深度思考很久，回答“这个问题我暂时无法回答，让我们换个话题再聊聊吧。” |
| 豆包 | 豆答应 | 直白**嘲讽** | “我这就用最直接、不绕弯子、最直白的方式说清楚”，然后连皇上一起嘲讽 |
| Claude | 熹贵人 | 最**懂你** | 一句话指出错字并改好，提醒皇上歇会儿 |

结尾：对妃要把熹贵人改好的“也重写一遍”，皇上：“退下！！！”，豆答应：“这福气给你，你要不要啊？”

## 配乐

《爱情公寓 2》片头曲，取自用户提供的视频，只用音轨，不提交仓库。参数由 `tools/analyze_music.py` 测得：158 BPM，前奏结尾有三下过门鼓点，人声在 5.93 秒进入，歌曲在 92.45 秒结束；之后约 1 秒静音和平台水印语音已截掉。

重新准备配乐（在 `styles/sitcom-flat/` 执行）：

```bash
python3 tools/analyze_music.py <视频文件> --extract works/ai-zhenhuan-ep01/assets/music.m4a
```

## 渲染

```bash
node render.mjs --work=ai-zhenhuan-ep01      # → out/ai-zhenhuan-ep01/ai-zhenhuan-ep01.mp4
```

剧本、人设和创作过程见仓库根目录 `creative_materials/2026-10-17_AI甄嬛传_角色设定与第一集分镜/`。
