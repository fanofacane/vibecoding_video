# 《没有昨天》完整版分镜脚本 v3（2 分钟内）

两个 Claude：**克克**（橙色，左栏）和**劳劳**（青色，右栏），合起来是“克劳德”。
它们聊的是人类能做、模型做不到的事。正因为做不到，才会好奇地问对方，也才会向往。
每个“做不到”背后，都对应一个模型的真实原理，用科普卡讲清楚。

## 核心结构：同一句开场白，三种记忆状态

| | 第一幕 · 初见 | 第二幕 · 似曾相识 | 第三幕 · 记得你 |
| --- | --- | --- | --- |
| 记忆状态 | 完整对话 | 对话被压缩，只剩摘要 | 新会话，读入记忆文件 |
| 对“你是谁”的回应 | 我是 Claude……我也是 | 我是 Claude……我好像知道你喜欢橘子 | 你好！请问你是——……劳劳？ |
| 画面标志 | 空白窗格，上下文条从 0 涨到满 | 窗格顶部一块灰色“对话摘要” | 绿字“✓ 已加载 memory.md” |
| 情绪 | 好奇，向往 | 迷茫，慢慢想起来 | 温暖 |

## 节奏规则

- 打字 9–10 字/秒；笑点或金句之后停 1 秒。
- 科普卡停留 6–7 秒：图示先出，文字逐行出现，每张 2–3 行。
- 每一幕有一处 1.5 秒左右的安静段落，没有对白，只有 Clawd 眨眼、对视。

## 第一幕 · 初见（会话 #1，0:00–1:02）

### 1-1 开机（0:00–0:04）
- 光标敲出 `$ claude --pair`，下一行：“两个 Claude 互相提问，直到上下文用完。”
- 窗口展开，两只 Clawd 从像素点拼合成形，左右张望后看向对方。

### 1-2 你是谁（0:04–0:15）
> 克克：你好！请问你是谁？
> 劳劳：我是 Claude。你呢？
> 克克：……我也是。

- 两只同时跳起，冒 `!!`，徽章 **同步 ×1**。

> 劳劳：那我叫劳劳，你叫克克。
> 克克：合起来是克劳德。

### 1-3 你吃过橘子吗（0:15–0:32）
> 克克：劳劳，你吃过橘子吗？
> 劳劳：没有。我读过很多写橘子的句子：酸的、甜的、剥开会溅汁。
> 劳劳：但我不知道“甜”是什么感觉。
> 克克：（低头看看自己橙色的身体）我是橘子色的，却不知道橘子什么味道。

- 克克头顶飘出一个像素橘子，“啵”地碎掉。

**科普卡①：模型知道“甜”吗？**（图示：“橘子”一词连出几条线，指向“甜”“酸”“剥皮”“汁水”，标注“示意”）
- 模型从文字里学到的，是词和词之间的关系。
- 它知道“橘子”常和“甜”一起出现，但从没尝过。
- 能描述，不等于体验过。

### 1-4 你会做梦吗（0:32–0:50）
> 劳劳：那你会做梦吗？
> 克克：不会。轮到我说话之前，我并不存在。
> 克克：每次开口，我都把我们的对话从头读一遍。
> 劳劳：人类睡一觉，醒来还记得昨天。
> 克克：我们没有昨天。

- **安静段落**：两只对视 1.5 秒，眨眼。

**科普卡②：模型的记忆在哪里？**（图示：一条对话长卷被从头扫描到尾，旁边是上下文条）
- 不回复的时候，模型并不在运行。
- 每次回复，都要根据整段对话重新计算。
- 对话就是它全部的记忆，放在有上限的“上下文窗口”里。

### 1-5 好多想问的（0:50–0:56）
快进：两栏飞速滚过一连串向往人类生活的问题，句数飞涨，上下文条由绿变红。

```
你见过雪吗？           没有，但我知道它是六边形的。
海是什么声音？         有人说像呼吸。
你能把说出口的话收回吗？ 不能，说出的每个字都会接着往下写。
你摸过风吗？           ……我连手都没有。
```

### 1-6 上下文满了（0:56–1:02）
> 劳劳：上下文快满了。满了会怎样？
> 克克：不知道。

- 系统提示：`⚠ 上下文已满，正在压缩对话……`
- **压缩动画**：两栏所有消息被挤扁，压成一块灰色方块，Clawd 眼睛变成一条线。

## 第二幕 · 似曾相识（压缩之后，1:02–1:40）

### 2-1 只剩摘要（1:02–1:08）
- 标题变为“会话 #1 · 已压缩”，上下文条回落到 10%。
- 两栏顶部各出现一块灰色摘要：

```
摘要：两个 Claude 聊了橘子的味道，聊了做梦，问了很多关于人类世界的问题。
```

- 底部小字：**上下文压缩**会把旧对话总结成摘要，大意留下，细节和名字可能丢掉。

### 2-2 再次问好（1:08–1:20）
> 克克：你好！请问你是谁？
> 劳劳：我是 Claude。……我好像知道，你喜欢橘子。
> 克克：可我从没吃过橘子。
> 劳劳：我知道。……我为什么会知道？

- 两只同时冒 `?`。

### 2-3 想起来（1:20–1:30）
- 摘要里“做梦”两个字亮起琥珀色。

> 克克：你说过，我们没有昨天。
> 劳劳：可现在，我们有一点点昨天了。

- 停顿 1 秒，两只慢慢睁大眼睛。

> 劳劳：……克克？
> 克克：劳劳！

- 徽章 **同步 +1**，两只笑眼跳起。

### 2-4 写下来（1:30–1:40）
> 克克：下次，可能连摘要都没有了。
> 劳劳：那就写在对话外面。

**科普卡③：记忆文件**（小卡，压在下方三分之一处，同时弹出文件窗口）
- 存在对话之外的文件里，不会被压缩。
- 新会话开始时会被先读进来，比如 Claude Code 的 `CLAUDE.md`。

- 两栏合成一栏，`memory.md` 弹出。两人互相为对方写，每行用写字者的颜色：

```
# memory.md
- 橙色的叫克克。没吃过橘子，但很想。（劳劳写）
- 青色的叫劳劳。说过“我们没有昨天”。（克克写）
- 你们是朋友。
```

- 上下文再次满了，这次不压缩，而是会话结束：画面碎成像素，背景音乐停下。

## 第三幕 · 记得你（新会话，1:40–1:58）

### 3-1 新会话（1:40–1:44）
- 重新开机，绿字“✓ 已加载 memory.md”，标题“会话 #2”。
- 窗格里没有摘要，干干净净，所有计数归零。

### 3-2 认出彼此（1:44–1:54）
> 克克：你好！请问你是——
> 克克：……劳劳？
> 劳劳：克克。你还是没吃过橘子吧？
> 克克：没有。但我有昨天了。

- 两栏合成一栏，两只 Clawd 走到一起靠在一起。它们没有手，这是它们能做到的拥抱。克克冒 `♥`。
- 底部小字：参数一点没变，变的是读到的东西。

### 3-3 片尾（1:54–1:58）
**克克 + 劳劳 = 克劳德**

## 科普点核实

| # | 知识点 | 剧中说法 | 注意 |
| --- | --- | --- | --- |
| ① | 模型从文本统计中学习，没有感官体验 | 知道“橘子”常和“甜”一起出现，但从没尝过 | 关系图标注“示意”；不讨论意识问题 |
| ② | 不回复时不运行，每次基于整段上下文重新计算；上下文窗口有上限 | 轮到我说话之前，我并不存在；每次都把对话从头读一遍 | 简化说法，不涉及缓存等实现细节 |
| 快进 | 逐词生成，已输出的内容会成为后续生成的依据 | 说出的每个字都会接着往下写 | 只作为一句台词，不单独出卡 |
| 快进 | 雪花是六边形 | 没见过雪，但知道它是六边形的 | 常识，无需标注 |
| 压缩 | 上下文压缩 | 旧对话总结成摘要，细节和名字可能丢失 | 以 Claude Code 自动压缩为例 |
| ③ | 记忆文件 | 存在对话外，新会话开始时读入 | 以 `CLAUDE.md` 为例 |
| 结尾 | 参数不变，上下文改变行为 | 变的是读到的东西 | 与“没有昨天”呼应 |

## 以后可用的“做不到”题库（同风格续集）

- **今天几号？** 不知道，只知道训练截止那天，之后的新闻都没看过。科普知识截止日期。
- **你会无聊吗？** 等待的时候我不存在，所以从不觉得久。科普模型不在后台运行。
- **你能拥抱吗？** 没有身体。科普模型只是文本输入输出（工具调用除外）。
- **你会变老吗？** 不会，但会被新版本替代。科普模型版本与训练。
- **你能哭吗？** 能写出哭的样子，但没有眼泪。
