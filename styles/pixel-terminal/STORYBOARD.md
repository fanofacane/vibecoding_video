# 《橙色暗号》样片分镜（约 35 秒）

两个 Claude 被放进同一个终端：**克克**（橙色，左栏）和**劳劳**（青色，右栏），合起来是“克劳德”。
样片把完整故事压成一条主线：相遇 → 发现很像 → 科普 → 失忆危机 → 记忆文件 → 新会话里认出彼此。

时间为当前 `src/script.js` 编译结果；改台词后会自动重排。

## 表演原则

- **字是台词，Clawd 是演员。** 每句台词都配一个身体反应：说话时上下跳，听对方说话时眼睛看向对方，吃惊时跳起并冒 `!!`，尴尬时闭眼冒汗。
- **界面就是道具。** 计数徽章负责笑点（“同步 ×N”“很好的问题 ×N”），上下文进度条负责紧张感，双栏合并负责情感。
- **每段只讲一件事。** 科普卡只讲一个知识点，三行以内；对白每句 20 字以内。
- **反差制造笑点。** 越想表现得不一样，越暴露两人一模一样。
- **结尾有回报。** 失忆后什么都不记得，只靠记忆文件里的一行字认出对方。

## 科普点核实

| 知识点 | 样片中的说法 | 说明 |
| --- | --- | --- |
| 同一模型输出相似 | 同一套参数，看到同一个问题，算出的概率表几乎一样 | 简化说法：上下文不同时分布也会不同 |
| 偏爱 7 | 人类被问到时也最爱说 7 | 只说“最爱”，不给真实比例；画面数字标注为示意 |
| 采样 | 骰子动画在概率条之间跳动 | 示意下一个 token 按概率抽取 |
| 上下文窗口 | 进度条填满后新会话不保留旧对话 | 不写具体窗口大小 |
| 记忆文件 | “写进记忆文件，新会话会先读它” | 对应 Claude Code 在会话开始时读取 `CLAUDE.md` 等记忆文件 |
